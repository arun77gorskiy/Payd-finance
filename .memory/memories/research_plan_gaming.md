# План исследования: Gaming криптопроекты (2025-2026)

## Цель
Создать список 30+ фундаментально сильных и реально существующих Gaming криптопроектов в формате JSON.

## Структура задачи

### Шаг 1: Подготовка
- [x] Создать директорию data/initial-universe
- [x] Составить список проектов из задания (~40 проектов)

### Шаг 2: Исследование и верификация проектов
Для каждого проекта найти:
- coingeckoId (slug)
- githubOrg (организация на GitHub)
- актуальное описание
- website
- подтверждение существования в 2025-2026

### Шаг 3: Создание JSON файла
- Создать валидный JSON массив
- Сохранить в data/initial-universe/gaming.json

### Шаг 4: Финальная проверка
- Валидация JSON
- Проверка всех обязательных полей
- Убедиться, что 30+ проектов
