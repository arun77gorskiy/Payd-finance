# Content Structure Plan - Payd_Finance

## 1. Material Inventory

**Content Context:**
- **Niche:** Crypto / Trading / AI / Education / SaaS
- **Positioning:** Institutional SaaS, no "info-business", premium trust.
- **Target:** Traders, Investors, AI enthusiasts.

**Visual Assets:**
- `imgs/` (Need: UI Dashboard screenshots, abstract data visualizations, risk management charts)
- **Logos:** Partner/Exchange logos for Trust section.

## 2. Website Structure

**Type:** SPA (Single Page Application)
**Reasoning:** Classic landing page structure (~2000px height), linear narrative (Problem -> Solution -> Product -> Trust), focused on a single conversion action (Get Access/Demo).

## 4. Content Analysis

**Information Density:** Medium
- **Reasoning:** Financial products require precision (terms, data), but marketing layer must remain digestible.
**Content Balance:**
- Images: 30% (UI shots are critical to prove "SaaS" claim)
- Text: 70% (Value proposition, features, explanations)
- Content Type: **Trust-Focused**. Heavy emphasis on "Institutional", "Risk Management" to counter crypto-skepticism.
